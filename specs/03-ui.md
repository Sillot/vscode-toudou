# Toudou — Interface utilisateur

## Vue container

Une entrée dans l'Activity Bar avec l'icône Toudou, contenant **deux panneaux** :

### Panneau "Todos"

TreeView mixte :

```
☐ Revoir le design du header
☐ Corriger le bug #42
▾ Backend (2)
    ☐ Migrer la base de données
    ☐ Ajouter l'endpoint /users
▸ DevOps (1)
```

**Noeuds racine** = les todos sans catégorie (en haut) + les catégories
- Les todos sans catégorie apparaissent en premier, triées par `order`
- Les catégories apparaissent ensuite, triées par `order`
- Pas de catégorie "Inbox" : les nouvelles todos sont créées sans catégorie par défaut

**Catégories** (noeuds parents)
- Affichent le nom et le nombre de todos actives entre parenthèses
- Dépliables/repliables
- Reordonnables par drag & drop
- Toutes les catégories peuvent être renommées et supprimées

**Todos** (noeuds enfants ou racine)
- Affichent le titre
- La description est visible en **tooltip** au survol
- Reordonnables par drag & drop (au sein d'une catégorie, entre catégories, ou vers/depuis le niveau racine)

### Panneau "Historique"

TreeView plat, ordre chronologique inversé (les plus récentes en haut) :

```
✓ Configurer le CI (complété le 02/04/2026)
✓ Setup initial du projet (complété le 01/04/2026)
```

- Chaque entrée affiche le titre et la date de complétion
- La description originale est visible en tooltip

## Actions — Panneau Todos

### Barre de titre du panneau
| Action | Icône | Comportement |
|--------|-------|-------------|
| Ajouter une todo | `$(add)` | Lance le flow d'ajout (voir ci-dessous) |

### Menu contextuel d'une catégorie (clic droit)
- Renommer la catégorie
- Supprimer la catégorie (les todos deviennent sans catégorie, remontées en haut)

### Menu contextuel / actions inline d'une todo
| Action | Icône | Position | Comportement |
|--------|-------|----------|-------------|
| Compléter | `$(check)` | Inline | Déplace dans l'historique |
| Supprimer | `$(trash)` | Inline | Suppression définitive |
| Éditer | `$(edit)` | Menu contextuel | Édition inline du titre |
| Éditer la description | — | Menu contextuel | Input box pour la description |
| Changer de catégorie | — | Menu contextuel | Quick pick des catégories |

## Actions — Panneau Historique

### Barre de titre du panneau
| Action | Icône | Comportement |
|--------|-------|-------------|
| Purger l'historique | `$(clear-all)` | Supprime tout l'historique après confirmation |

### Menu contextuel / actions inline d'une todo complétée
| Action | Icône | Position | Comportement |
|--------|-------|----------|-------------|
| Restaurer | `$(debug-restart)` | Inline | Remet la todo dans sa catégorie d'origine (ou sans catégorie si elle n'existe plus) |

## Flow d'ajout d'une todo

1. **Input box** : "Titre de la todo" (requis)
2. **Quick pick** : choix de la catégorie
   - Option "Aucune catégorie" en haut (par défaut)
   - Option "➕ Nouvelle catégorie..." 
   - Liste des catégories existantes
   - Si nouvelle catégorie : input box pour le nom
3. **Input box** : "Description (optionnel)" — peut être laissé vide (Entrée pour passer)

La todo est créée sans catégorie (en haut du TreeView) ou dans la catégorie sélectionnée, en dernière position.

## Flow d'édition inline

- Titre : input box pré-rempli avec la valeur actuelle
- Description : input box pré-rempli (vide si pas de description)
- Catégorie : quick pick pré-sélectionné sur la catégorie actuelle
