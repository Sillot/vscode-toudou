# Toudou

A simple todo list extension for VS Code, displayed in the sidebar.

## Features

- Add, toggle, and remove todos from the activity bar
- Persistent storage per workspace
- Clear all completed todos in one click

## Development

Open in VS Code with Dev Containers to get the full dockerized dev environment.

### Commands

| Script | Description |
|---|---|
| `npm run compile` | Build the extension |
| `npm run watch` | Build in watch mode |
| `npm run typecheck` | Run TypeScript type checking |
| `npm run lint` | Run ESLint |
| `npm run format` | Format with Prettier |
| `npm run package` | Package as `.vsix` |
| `npm run install-local` | Package and install in VS Code |

### Debug

Press `F5` to launch an Extension Development Host with the extension loaded.
